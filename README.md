# Portfolio Website

This repository contains the source code for my personal portfolio website. It is a React application styled with Tailwind CSS and designed to showcase my Android development projects, skills, experience, and contact information.

## Features

- Responsive single-page layout with sections for About, Skills, Projects, Experience, Education, and Contact.
- Dark/light theme toggle.
- Smooth scrolling and reveal animations.
- Projects include links to the Google Play Store where applicable.

## Development

```bash
# install dependencies
npm install

# start development server
npm run dev
```

## Build

```bash
npm run build
```

Deployed site can be hosted via GitHub Pages, Netlify, or Vercel.
